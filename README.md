# Проект по разработке веб приложения на django 

## Описание
В этом проекте я буду практиковаться в разработке веб-приложения (интернет-магазина).

## Установка

Клонируйте репозиторий:
```
git clone https://github.com/Denis-Guryanov/django_project.git
```

Установите зависимости 
```
poetry install
```
